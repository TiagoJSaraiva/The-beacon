# Sistemas

Uma nota por sistema (`movimento.md`, `combate.md`...), criada quando o sistema passa a existir.

Modelo:

```markdown
# <Sistema>

## Propósito
Uma ou duas frases.

## Componentes
Cenas e scripts envolvidos, com o papel de cada um.

## Regras
As regras de gameplay que o código implementa (valores, limites, condições).

## Sinais
Emitidos e escutados.

## Testes
Onde estão e o que cobrem.
```
